## 2. 何が起きたか(overlay +86k → Tester −80k の反転要因)

### 2.1 whipsaw増幅(S8、主因)— ユーザー警告どおりの型
overlay はエントリー系列を固定していたが、実走では **切り→cooldown→再エントリー→切り**
のループが発生。D2000 の basket数はベースラインの3〜4倍
(MAR_MAY 100k: 123→460、50k: 79→503)。下降継続月では
88回×−2,000円級の切りコストを勝ち回収が相殺できず、in6 合計 −131,414
(ベースライン −51,673)。**「トレンドに逆らう再突入の頻度増幅」というユーザーの
指摘した破綻型が、下降レジーム内で発現した。**

### 2.2 動的閾値との競合(S1/S2 の敗因、実装上の発見)
HardStop閾値は**残高比例(≈残高の8%)**。50k run で残高が磨り減ると閾値が
~2,400円まで縮み、hedge発動(閾値の~78% ≈ **−1,800円**)が**固定BOX床2,000円より
浅くなり box を追い越す**。hedge凍結された basket は net が動かず box が二度と
発火できない → HTE 48件・HS 3件の漏れ。100k run(閾値~8,400)では発生せず。
→ **固定額BOXと残高比例リスク系の混在は構造的に破綻する**(設計審査の必須論点)。

### 2.3 D1600 の皮肉な示唆
D1600 は連敗カウント経由で取引が絞られ(entries 190 vs D2000の460)、
in6 合計 **−41,273 = ベースラインより+10,400 改善**(D2000/D2400は悪化)。
つまり本サンプルで機能したのは「切って再突入する」ではなく**「切ったら止まる」**。
再エントリー抑制が box の成立条件であることを Tester が示した。

## 3. W4 上昇ストレス(Feb 2026, +9.85%、実行前固定選定)— 結果の反転

| arm | 100k net | 50k net | HS | 最悪basket | MaxDD(100k/50k) |

| BOX D2000 | **+9,320** | **+5,540** | 0 | −2,021 | 10,011 / 10,219 |

- 「トレンドが変わればBOXは負ける」の直接検証 → **この窓では逆**。上昇月に出血
  したのは現行EA(4週でHS 8件、最悪−9,123)で、BOXは全指標で優位。
- 理由: 上昇月はエントリーエンジンの順行が早く、切りが浅く済み再突入も勝ちに
  変わる。下降継続月は逆に再突入が切られ続ける。
  → **BOXの成否はレジームの向きではなく「エントリーエンジンの再突入品質」に依存**。

## 4. 結論と次の設計審査論点(実装はしない)

1. 事前登録どおり **in-sample不合格を記録**(S1/S2/S3/S5)。「レンジ取りが
   もっとも勝てる」は**この実装形(固定床+即再突入)では不成立**。
2. ただし**尾部圧縮は全窓で成立**(最悪 −2,4xx vs −9,1xx、W4含む)。破綻リスク
   軽減という本来目的に対する box の価値は Tester でも確認された。

   - **R1: BOX_EXIT後の再エントリー抑制**(同方向ban/長cooldown/日次上限。
     D1600の偶発的成功が方向性を示す)

     動的閾値との追い越し競合を構造的に解消)
