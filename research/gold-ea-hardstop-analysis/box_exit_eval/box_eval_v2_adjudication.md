## 読み取り(判定合成へ持ち帰る知見)

1. **尾部圧縮は3度目の確認**: 全10run 最悪 −2,015(ベースライン −9,123)、
   HardStop 0件(backstopすら不発)、hedge 0件。**「破綻しない構造」としての
   BOXは完成している**。壊れているのは期待値側。
2. **レジーム軸の再定義**: 勝敗を分けたのは上昇/下降ではなく**トレンド/チョップ**。
   - トレンド窓(W4 2月+9.9%、6月−11.4%): v2 全勝(+4,946 / +26,568)
   - チョップ窓(4月−1.1%、5月−1.8%): v2 全敗(−20,705 / −22,557)
   - 当初仮説「レンジ(チョップ)で取っていくスタイルが勝つ」は**実走では逆**:
     チョップこそ box が最も出血する(浅い床に往復でヒットし続ける)。
3. **再突入抑制(R1)は不十分**: HardStop同格の事後機構でも basket 1.6〜4.9倍。
   HS用cooldown/origin blockは「稀な大事故」向けの設計であり、
   高頻度の浅い切りを抑える器ではなかった(T5 FAIL)。
4. MAR_MAY 50k(v1で最悪だった資本減衰run)は v2 で改善(+5,253)—
   R2 の残高比例床は意図どおり機能した。
