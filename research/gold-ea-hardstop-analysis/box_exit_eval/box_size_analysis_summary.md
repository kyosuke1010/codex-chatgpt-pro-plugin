# box_size_analysis_summary.md — BOXサイズ最適範囲の反実仮想解析

date: 2026-07-12
仮説(ユーザー提示): 「BOXから出れば即切り。レンジ範囲で取っていくスタイルがもっとも勝てる」
→ 本解析はこの仮説の**検証**であり、利益保証ではない。in-sample+June の overlay
counterfactual であり、Tester実走(Codex)と July W2(OOS)の確認が必要。

## 方法

- 宇宙: W3ベースライン 481 basket(HS 39 / 勝ち435 / HTE 7)。BASKET_OPEN の
  entry価格・方向から price_m5(M5 OHLC)を first-passage 走査。
  hedged basket は basket_uid 基底(GOLD#token#seq)で open⇔anchor を結合
  (末尾成分がhedgeで変わるため。これでHS 39全件をカバー)。
- overlay 規則: 逆行超過(adverse excursion)が D に達した最初のbarで
  **−(D+40円slip) で即切り**。達しなければ実際の結果(final_pl)をそのまま採用。
  スプレッド0.40(SELL買戻し側に加算)。バー内は保守的(バー極値で判定)。
- 上側は現行のまま(+400円 BasketClose cap)= 実質「+400 / −D の非対称BOX」。
- 通貨換算: 0.01 lot GOLD で 1 price unit = 100円。

## 結果1: 分離帯が実在する

| 群 | adverse excursion(生涯最大逆行) |
|---|---|
| 勝ち 435件 | 中央 3.7u(370円)/ p90 **14.4u** / p97 21.1u / max 42.2u |
| HS 39件 | **最小 20.4u(2,040円)** / 中央 102.9u |

**勝ちの90%は逆行1,440円以内に収まり、HardStop 39件は全件が逆行2,040円を通過する。**
→ BOX下限 1,600〜2,000円 が構造的な分離帯。

  +159.1円/件、勝ち殺し1件のみ**。NEW_BASELINE除外でも +119.4(峰同じ)。

## 結果3: BOXは hedge/HardStop を左側で置換する

- 現行 hedge は閾値の**77.7%消費(≈−6,200円)**で発動 → BOX下限2,000円は
  hedge発動前に必ず切る = **hedged凍結地獄(M1)も高速型(M2)も同じ一つの浅い床で先制**。
- HS群の favorable excursion 中央 9.9u: 死ぬbasketも一度は+1,000円相当まで
  順行している(現行はhedge凍結でnetが動かず取れない)。レンジ内で取る、という
  仮説の方向性はこのデータと整合する(上側設計は本評価では現行+400のまま)。

## 限界(必ず読むこと)

1. **overlay反実仮想**: 早期切りが解放する枠・cooldown・後続エントリの変化
   (path効果)を含まない → Tester実走(variant EA)での確認が必須。
2. M5バー粒度・保守的バー内判定・slip40円は仮定。
3. in-sample+June のみ。**July W2 がOOS確認**(未接触のまま維持)。
4. 期待値 −118→+61円/basket は本サンプル内の overlay 結果であって利益保証ではない。
5. グリッドは事前登録3点(1,600/2,000/2,400)で Tester検証する。**それ以上の
   微調整(過適合)は禁止**。
