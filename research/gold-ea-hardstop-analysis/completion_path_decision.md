# completion_path_decision.md — EA完成への経路決定

date: 2026-07-14
契機: ユーザー質問「8月まで完成に進めないのか / BOX回避なら完成手段があるのか /
過去データで利益が出る形に調整して完成できるならやれ」への回答と処置。

## 1. 決定事項

### 1-A. 「過去データで利益が出るまで調整」は実施しない(恒久)

根拠(本プロジェクトの実測、2回):
- overlay解析の +86,346円予測 → Tester実走で −79,741円悪化(box v1)
- 修正版(v2)でも in6 −100,202 vs ベースライン −51,673
- run毎に最適パラメータを後出し選択すれば in-sample黒字は**いつでも製造可能**だが、
  未接触データで再現しない(=実弾で再現しない)ことが上記で実証済み。
- 「完成」の定義: **調整に使っていないデータで edge が生き残ること**。

### 1-B. 8月は「作業再開日」ではなく「判定可能日」

- 停止中なのは「BOX系の in-sample 再修正・再走」のみ。
- 設計・凍結・W2準備は現在も進行可能(本文書がその一部)。
- 2026-08-01: July W2 完結 → (i) ベースラインEAの OOS判定(当初登録どおり)、
  (ii) 下記 1-C 凍結候補の初回接触判定。

### 1-C. 完成候補 v3 の事前凍結(July を見る前に登録する)

**候補名: TREND_GATED_SURVIVAL(トレンドゲート付き生存型)**

データ根拠(in-sample から仮説生成、検証は未接触データのみ):
- 全構成の負けはチョップ月に集中(4月−1.1%/5月−1.8%: box v2 で −20,705/−22,557差)
- トレンド窓では box構成が全勝(W4 2月+9.9%: +26,568差 / June −11.4%: +4,946差)
- v2 で確定済みの部品: 残高比例BOX床(生存レール、最悪−2,015円・HS 0)、
  hedge無効化(無害)、HardStop backstop

仕様(凍結。8/1 の検証まで変更禁止):
1. ベース = box v2 variant(`8B95EA45`)そのまま
2. 追加は1つだけ: **エントリーゲート** — 既存の `HTFState` /
   `MaTrendDirection` / `TrendMainDirection` が**一致してトレンドを示す時のみ**
   新規basketを許可(チョップ=不一致時はエントリー停止。既存計算値の参照のみ、
   新指標・新閾値を作らない)
3. パラメータ調整なし(box床 min(2000, 0.5×thr) とゲート定義は本日凍結)
4. 検証: **2026-08-01 以降、July W2 データで1回のみ**(in-sample へは接触しない)
   - 合否: July で (a) ベースラインより期待値改善、(b) HS=0、(c) MaxDD縮小、
     (d) basket数がベースライン±50%内
   - 合格 → 8月をW5窓としてもう1期OOS → 本番昇格審査
   - 不合格 → エントリーエンジン再設計を正式議題化(Exit側の手段は尽きたため)

### 1-D. 正直な見通し(利益保証はしない)

- 現ベースラインの実測: 期待値 −147円/basket、4ヶ月中黒字は MAY 50k のみ。
  **どのExit改良でも、負のエントリー流を黒字化できないことは v2 で実証済み。**
- v3 候補の勝算はデータ上の構造(チョップ回避+トレンド窓の box優位)に基づくが、
  **July で初めて本物の検証を受ける**。不合格の場合、誠実な結論は
  「エントリーエンジンの再設計が必要」であり、それも完成への正当な一歩である。
